# Procedural Fantasy Placeholder Assets

- `tiles/courtyard.png` and `tiles/courtyard.tres` are original procedural medieval grass and cobblestone 64×32 isometric tiles generated by `scripts/tools/generate_tiles.gd`.
- `fonts/after_hours.png`, `fonts/after_hours.fnt`, `fonts/after_hours.tres`, and `fonts/pixel_theme.tres` form the original 5×7 pixel font and warm medieval HUD theme generated by `scripts/tools/generate_font.gd`.
- Aren (player), Bellhaven Belfry, Cottage, Blacksmith Workshop, trees, lanterns, Village Well, Anvil Plinth, and the Stone Rune Pedestal are rendered using original Godot primitive pixel art in their respective scripts.
- `audio/` and `sprites/` are reserved for expanded assets in Phases 1–4.
